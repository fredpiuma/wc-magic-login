# Changelog

Todas as mudanças relevantes do plugin ficam registradas aqui.

## [1.0.0] - 2026-11-27

Primeira versão publicada.

- Login com link mágico e código OTP de 6 dígitos enviados por e-mail, com expiração configurável e uso único.
- Limite de 5 tentativas de código incorretas por sessão.
- Envio opcional por webhook (EvolutionAPI/BaileysAPI) usando o telefone de faturamento do cadastro do cliente, que não pode ser informado no formulário.
- Assunto do e-mail com o código no início, para copiar direto da notificação do celular.
- Configurações em **WooCommerce → Configurações → Login Mágico**.
- Compatível com o Fluid Checkout e com template sobrescrevível pelo tema.
- Instruções de instalação no README e zip de instalação anexado aos releases.
